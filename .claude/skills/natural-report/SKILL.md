# 보고서 다듬기 (natural-report)

팀장 보고용 보고서를 **개조식 단답형**으로, **AI 티 없이**, **오와 열을 맞춰** 작성하거나 다듬는다.
내용·사실·숫자는 절대 바꾸지 않는다. 표현과 구조만 고친다.

## 1. 문장 끝: 명사형 단답

모든 항목은 명사나 명사형으로 끝낸다. 서술어 어미를 쓰지 않는다.

| 쓰지 않음 | 이렇게 |
| --- | --- |
| 성장 가능성을 확인함 | 성장 가능성 확인 |
| 매출이 감소하였음 | 매출 감소 |
| 검토가 필요할 것으로 보임 | 검토 필요 |
| 다음 달 추진할 예정임 | 12월 추진 예정 |
| 고객 만족도가 개선되었습니다 | 고객 만족도 개선 |

- 금지 어미: `~함`, `~임`, `~됨`, `~하였음`, `~것으로 보임`, `~습니다`, `~해요`
- 한 항목은 한 줄, 가능하면 **30자 이내**
- 주어·조사는 뜻이 통하면 최대한 생략 (`매출이 → 매출`)

## 2. AI 티 나는 단어·흐름 제거

**단어** — 아래 표현은 빼거나 구체적인 말로 바꾼다.

| AI 티 | 바꾸는 방법 |
| --- | --- |
| 다양한, 효과적인, 핵심적인, 혁신적인, 전략적인 | 삭제하거나 구체적인 내용·숫자로 대체 |
| ~를 통해, ~에 있어, ~측면에서, ~관점에서 | `~로`, `~에서` 또는 삭제 |
| 극대화, 최적화, 시너지, 고도화, 인사이트 | 실제로 무엇이 얼마나 바뀌는지로 대체 (`처리 시간 20% 단축`) |
| 중요한 역할을 함, 기여함, 의미가 있음 | 결과만 적기 |
| 또한, 아울러, 따라서, 결론적으로, 나아가 | 삭제 (항목 나열 자체로 연결됨) |
| ~라고 할 수 있음, ~로 판단됨 | 단정형 (`~ 판단` 대신 근거 + 결론) |

**흐름** — 아래 습관을 없앤다.

- 무조건 세 개씩 나열하는 습관 → 실제 개수대로 (2개면 2개)
- 모든 항목 길이·구조가 똑같은 기계적 반복 → 중요도에 따라 길이 차이 허용
- 서론·요약 반복 ("본 보고서는 ~을 다루고자 함") → 삭제, 바로 결론부터
- 의미 없는 마무리 ("지속적인 노력이 필요함") → 삭제하거나 구체적 다음 단계로
- 이모지, 굵은 글씨 남발, 따옴표 강조 → 사용 안 함

## 3. 구조: 두괄식 + 단계 기호

결론·요청 사항을 맨 위에 둔다. 단계는 **최대 3단계**, 단계마다 기호를 고정한다.

```
□ 1단계 (주제·결론)
  ○ 2단계 (세부 내용)
    - 3단계 (근거·수치)
```

- 같은 단계는 같은 기호, 같은 들여쓰기 (오와 열)
- 같은 단계 항목끼리 끝맺음 형태 통일 (전부 명사형)
- 비교·수치가 3개 이상이면 문장 대신 **표**로

## 4. 숫자·표기 통일

- 날짜: `2026.11.11.` / 기간: `11.1.~11.30.`
- 증감: `전년 대비 12.3% 증가`, `전월 대비 5건 감소`
- 금액: `1,250만 원`, `3.2억 원` (한 보고서 안에서 단위 하나로 통일)
- 천 단위 쉼표, 소수점 자릿수 통일
- 표 안 숫자는 **오른쪽 정렬**, 글자는 왼쪽 정렬, 헤더는 가운데 정렬

## 5. 서식 (파일로 만들 때)

Word·PowerPoint·Excel·HTML로 만들 때 적용한다.

- 글꼴: **맑은 고딕** (`Malgun Gothic`), 제목·본문·표 모두 동일
- 크기: 제목 16pt 굵게 / 소제목 12pt 굵게 / 본문 11pt / 표 10pt
- 줄 간격: 본문 1.3배 내외, 단락 사이 여백 일정하게
- 색: 검정 본문 + 강조색 1개 이하, 표 헤더만 연한 회색 배경
- 들여쓰기: 단계마다 같은 간격 (오와 열 정렬)
- 표: 가로 선 위주, 세로 선 최소화, 열 너비 내용에 맞게

## 6. 작업 순서

1. 원문에서 사실·숫자·고유명사를 먼저 확인 (바꾸지 않을 것)
2. 결론을 맨 위로 올려 두괄식으로 재배치
3. 단계 기호 정리 (□ ○ -)
4. 문장 끝을 명사형 단답으로 변경
5. AI 티 단어·흐름 제거
6. 숫자·표기 통일, 필요한 곳은 표로 변환
7. 아래 점검표로 최종 확인

## 7. 최종 점검표

- [ ] 모든 항목이 명사형으로 끝나는가 (`~함`, `~임`, `~습니다` 없음)
- [ ] 2장의 AI 티 단어가 남아 있지 않은가
- [ ] 같은 단계의 기호·들여쓰기·끝맺음이 맞는가 (오와 열)
- [ ] 원문 사실·숫자가 그대로인가
- [ ] 결론이 맨 위에 있는가
- [ ] 파일이면 맑은 고딕 적용했는가

## 출력

다듬은 보고서만 먼저 보여 준다. 그 아래에 **바꾼 점 3줄 이내**로 짧게 적는다.
원문 사실이 애매하거나 숫자가 서로 안 맞으면 고치지 말고 표시 후 질문한다.

## 예시

**원문**
> 또한 이번 분기에는 다양한 마케팅 활동을 통해 신규 고객 유입이 크게 증가하였으며, 이는 브랜드 인지도 향상에 중요한 역할을 한 것으로 판단됩니다. 따라서 향후에도 지속적인 노력이 필요할 것으로 보입니다.

**다듬은 결과**
```
□ 3분기 신규 고객 유입 증가
  ○ SNS 광고·체험 이벤트 효과
    - 신규 고객 전 분기 대비 18% 증가
  ○ 브랜드 인지도 상승 확인
□ 4분기 동일 채널 유지 예정
```
(원문에 수치·채널이 없으면 `[수치 확인 필요]`로 표시하고 지어내지 않는다.)
